# E-Commerce Sales & Customer Analytics

SQL Server project analyzing e-commerce sales, customers, products, and order performance.

## Key Insights
- Total delivered sales revenue: ₹17,829
- Top category: Electronics — ₹9,095
- Top product: Bluetooth Headphones — ₹3,998
- Top customer: Aarav Sharma — ₹9,191
- Highest sales month: August 2024 — ₹4,996

## SQL Skills Used
- JOINs
- GROUP BY and Aggregations
- CTEs
- Window Functions
- RANK()
- LAG()
